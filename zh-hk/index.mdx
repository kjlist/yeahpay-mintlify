YeahPay API 使用 HTTPS 和 JSON 提供支付、查詢、退款及收銀台服務。

## 環境地址

| 環境 | API 域名 |
| --- | --- |
| 沙盒 | `https://sandbox-api.yeahpay.net` |
| 生產 | `https://open-api.yeahpay.net` |

聯調使用沙盒環境，正式交易使用生產環境，並分別使用對應的應用憑證。在各介面頁面選擇環境，按該環境的完整請求路徑或產生的 cURL 調用。

<Warning>
  沙盒與生產使用不同的憑證。切換時同時更換介面環境路徑及對應的 `appId`、`apiKey`。
</Warning>

## 公共請求頭

應用憑證、公共請求頭和簽名規則集中在[請求授權](/zh-hk/api-authentication)。

## 對接流程

<Steps>
  <Step title="登錄沙盒商戶後台並建立憑證">
    先登錄沙盒環境的 PC 端商戶後台，再在後台建立 `appId` 和 `apiKey`，並將憑證安全地保存在伺服器端配置中。
  </Step>
  <Step title="產生簽名">
    序列化請求體一次，使用同一份原始 JSON 計算簽名並發送請求。查看[簽名規則與示例](/zh-hk/signature)。
  </Step>
  <Step title="完成沙盒環境聯調">
    驗證支付、查詢、逆向交易和非同步通知。支付或退款通知處理成功後，響應 Body 必須返回 `success`。
  </Step>
  <Step title="切換生產環境">
    在介面文件選擇生產環境，使用 `https://open-api.yeahpay.net` 下的完整請求地址和[生產商戶後台](https://payment.yeahpay.net/merchant/system/#/)的生產環境憑證。
  </Step>
</Steps>
