## 產品簡介

Unified Checkout（統一託管收銀台）是面向全球商戶的聚合型收銀台服務：商戶系統只需一次對接，即可接入信用卡、本地錢包、銀行轉賬等全球主流支付方式。消費者會被重定向至該託管頁面完成付款，商戶無需收集或存儲支付資料，因為敏感數據的採集與處理全部由Yeahpay負責，從而大幅降低商戶的 PCI-DSS 合規成本。

## 主要能力與優勢

- **一次對接，多種支付方式**：通過一套介面接入信用卡（VISA / Mastercard / AMEX）、微信、支付寶、銀行轉賬等全球主流支付方式
- **多端自適應**：自動識別 PC 端與移動端訪問環境，響應式佈局無縫適配不同屏幕尺寸
- **多語言支持**：內置中文、繁體中文、英文、日文，收銀台頁面可一鍵切換
- **智能支付路由**：按商戶配置、地區、歷史成功率等規則動態排序支付方式，提升支付**轉**化
- **降低 PCI-DSS 合規成本**：持卡人卡號、CVV 等敏感資料只在收銀台側處理，不經過商戶系統
- **安全風控內置**：HTTPS 全鏈路加密、防重放校驗、訪問域名白名單審核，攔截未授權來源與欺詐交易
- **高可用保障**：系統可用性 ≥ 99.95%，峯值處理能力 ≥ 1000 TPS，大促高峯也能穩定支付

## 接入使用流程

1. **商戶入駐與配置**：完成商戶入駐審核，取得 `merchantId` 與 `apiKey`，並提交需承載收銀台跳轉的訪問域名以供審核加入白名單
2. **調用介面取得收銀台 URL**：商戶系統傳入訂單資料（金額、幣種、商品資料、回調地址等）並簽名，調用取得收銀台介面，獲得唯一的收銀台 URL 與支付意圖 ID
3. **跳轉至收銀台頁面**：將消費者引導至該 URL，頁面自動識別訪問環境並展示對應的商品資料與可用支付方式列表
4. **消費者完成支付**：消費者選擇支付方式並提交，收銀台與對應支付方式完成驗證與扣款
5. **接收支付結果回調**：支付完成後，Yeahpay通過簽名回調將結果（成功/失敗/取消）通知商戶系統，商戶系統據此更新訂單狀態
6. **頁面結果跳轉**：收銀台自動將消費者引導至商戶指定的結果頁面，若未配置則展示內置的支付結果頁

## 常見問題 FAQ

**收銀台 URL 的有效期是多久？** 預設 24 小時，支持商戶按需配置。超過有效期後連結失效，需要重新調用介面取得新的收銀台 URL。

**支付失敗後可以重試嗎？** 可以。消費者可以選擇用原支付方式重試，也可以更換其他支付方式，重試次數不設上限，直至訂單超時（2 小時）。

**商戶需要存儲或處理消費者的卡號資料嗎？** 不需要。持卡人卡號、CVV 等敏感資料只在收銀台頁面採集和處理，不會經過商戶系統，相關 PCI-DSS 合規責任由Yeahpay承擔。

**跳轉收銀台時有什麼限制嗎？** 商戶承載收銀台跳轉的訪問域名需要提前審核並加入白名單，未審核、非法或缺失 Referer 的來源會被攔截。

**目前支持哪些地區和支付方式？** 目前支持香港、新加坡商戶，涵蓋銀行卡（VISA / Mastercard / AMEX）、微信、支付寶，香港地區移動端額外支持八達通，後續會持續擴展。
