YeahPay provides payment, query, refund, and checkout APIs over HTTPS with JSON payloads.

## Environment URLs

| Environment | API domain |
| --- | --- |
| Sandbox | `https://sandbox-api.yeahpay.net` |
| Production | `https://open-api.yeahpay.net` |

Use Sandbox for integration and Production for live transactions, with the matching application credentials. Select the environment on each API page and use its complete request path or generated cURL.

<Warning>
  Sandbox and Production use different credentials. Switch both the API environment path and its `appId` and `apiKey`.
</Warning>

## Common request headers

See [Request Authentication](/en/api-authentication) for application credentials, common headers, and signing rules.

## Integration flow

<Steps>
  <Step title="Sign in to the sandbox dashboard and create credentials">
    Sign in to the [sandbox merchant dashboard](https://sandbox.yeahpay.net/login) on a computer. Create an `appId` and `apiKey` there, then store them securely in your server-side configuration.
  </Step>
  <Step title="Generate the signature">
    Serialize the request body once. Use the same raw JSON string to calculate the signature and send the request. See [Signature rules and examples](/en/signature).
  </Step>
  <Step title="Complete integration testing">
    Verify payments, queries, reversal transactions, and asynchronous notifications. After processing a payment or refund notification successfully, return `success` as the response body.
  </Step>
  <Step title="Switch to production">
    Select Production on the API page. Use the full request URL on `https://open-api.yeahpay.net` with your production credentials from the [production merchant dashboard](https://payment.yeahpay.net/merchant/system/#/).
  </Step>
</Steps>
