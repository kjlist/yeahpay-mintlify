YeahPay API 使用 HTTPS 和 JSON 提供支付、查询、退款及收银台服务。

## 环境地址

| 环境 | API 域名 |
| --- | --- |
| 沙箱 | `https://sandbox-api.yeahpay.net` |
| 生产 | `https://open-api.yeahpay.net` |

联调使用沙箱环境，正式交易使用生产环境，并分别使用对应的应用凭证。在各接口页面选择环境，按该环境的完整请求路径或生成的 cURL 调用。

<Warning>
  沙箱与生产使用不同的凭证。切换时同时更换接口环境路径及对应的 `appId`、`apiKey`。
</Warning>

## 公共请求头

应用凭证、公共请求头和签名规则集中在[请求授权](/api-authentication)。

## 对接流程

<Steps>
  <Step title="登录沙箱商户后台并创建凭证">
    先登录[沙箱环境的 PC 端商户后台](https://sandbox.yeahpay.net/login)，再在后台创建 `appId` 和 `apiKey`，并将凭证安全地保存在服务端配置中。
  </Step>
  <Step title="生成签名">
    序列化请求体一次，使用同一份原始 JSON 计算签名并发送请求。查看[签名规则与示例](/signature)。
  </Step>
  <Step title="完成沙箱环境联调">
    验证支付、查询、逆向交易和异步通知。支付或退款通知处理成功后，响应 Body 必须返回 `success`。
  </Step>
  <Step title="切换生产环境">
    在接口文档选择生产环境，使用 `https://open-api.yeahpay.net` 下的完整请求地址和[生产商户后台](https://payment.yeahpay.net/merchant/system/#/)的生产环境凭证。
  </Step>
</Steps>
