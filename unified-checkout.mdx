## 产品简介

Unified Checkout（统一托管收银台）是面向全球商户的聚合型收银台服务：商户系统只需一次对接，即可接入信用卡、本地钱包、银行转账等全球主流支付方式。消费者会被重定向至该托管页面完成付款，商户无需收集或存储支付信息，因为敏感数据的采集与处理全部由Yeahpay负责，从而大幅降低商户的 PCI-DSS 合规成本。

## 主要能力与优势

- **一次对接，多种支付方式**：通过一套接口接入信用卡（VISA / Mastercard / AMEX）、微信、支付宝、银行转账等全球主流支付方式
- **多端自适应**：自动识别 PC 端与移动端访问环境，响应式布局无缝适配不同屏幕尺寸
- **多语言支持**：内置中文、繁体中文、英文、日文，收银台页面可一键切换
- **智能支付路由**：按商户配置、地区、历史成功率等规则动态排序支付方式，提升支付**转**化
- **降低 PCI-DSS 合规成本**：持卡人卡号、CVV 等敏感信息只在收银台侧处理，不经过商户系统
- **安全风控内置**：HTTPS 全链路加密、防重放校验、访问域名白名单审核，拦截未授权来源与欺诈交易
- **高可用保障**：系统可用性 ≥ 99.95%，峰值处理能力 ≥ 1000 TPS，大促高峰也能稳定支付

## 接入使用流程

1. **商户入驻与配置**：完成商户入驻审核，获取 `merchantId` 与 `apiKey`，并提交需承载收银台跳转的访问域名以供审核加入白名单
2. **调用接口获取收银台 URL**：商户系统传入订单信息（金额、币种、商品信息、回调地址等）并签名，调用获取收银台接口，获得唯一的收银台 URL 与支付意图 ID
3. **跳转至收银台页面**：将消费者引导至该 URL，页面自动识别访问环境并展示对应的商品信息与可用支付方式列表
4. **消费者完成支付**：消费者选择支付方式并提交，收银台与对应支付方式完成验证与扣款
5. **接收支付结果回调**：支付完成后，Yeahpay通过签名回调将结果（成功/失败/取消）通知商户系统，商户系统据此更新订单状态
6. **页面结果跳转**：收银台自动将消费者引导至商户指定的结果页面，若未配置则展示内置的支付结果页

## 常见问题 FAQ

**收银台 URL 的有效期是多久？** 默认 24 小时，支持商户按需配置。超过有效期后链接失效，需要重新调用接口获取新的收银台 URL。

**支付失败后可以重试吗？** 可以。消费者可以选择用原支付方式重试，也可以更换其他支付方式，重试次数不设上限，直至订单超时（2 小时）。

**商户需要存储或处理消费者的卡号信息吗？** 不需要。持卡人卡号、CVV 等敏感信息只在收银台页面采集和处理，不会经过商户系统，相关 PCI-DSS 合规责任由Yeahpay承担。

**跳转收银台时有什么限制吗？** 商户承载收银台跳转的访问域名需要提前审核并加入白名单，未审核、非法或缺失 Referer 的来源会被拦截。

**目前支持哪些地区和支付方式？** 目前支持香港、新加坡商户，涵盖银行卡（VISA / Mastercard / AMEX）、微信、支付宝，香港地区移动端额外支持八达通，后续会持续扩展。
